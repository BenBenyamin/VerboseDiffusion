§ 02 — Pipeline

Real image ↔ latent ↔ sample.

The whole system is a Latent Diffusion Model (LDM). Rather than operate on pixels directly, everything happens inside the 4-channel 64×64 latent space of Stability's sd-vae-ft-mse VAE. Training encodes AFHQ images once, caches the latents to disk, and never runs the VAE encoder again. Sampling runs the VAE decoder exactly once at the end to bring the final latent back to a 512×512 RGB image.

Latents are scaled by a training-time constant (scaling_const = 0.18215, matching SD's convention) so the diffusion process operates on a distribution with roughly unit variance.

§ 03 — UNet

Encoder → bottleneck → decoder.

The denoiser is a standard 4-level UNet operating on 4×64² latents. Three DownBlocks halve the spatial dimensions (64² → 32² → 16² → 8²) while widening the channel count (128 → 256 → 384 → 512). A MidBlock at the bottleneck alternates ResBlocks with self-attention. Three UpBlocks mirror the decoder, consuming the skip connections harvested from the down path.

Attention lives at the two deeper resolutions (attn_levels = [false, true, true]) and inside the bottleneck. It's skipped at the top level because MultiheadAttention at 64² is quadratically expensive and the pixels there don't need long-range interaction yet.

The time+class embedding is a separate rail: an integer timestep goes through a sinusoidal encoder plus a small MLP, and the class embedding table adds into that same vector. The result (temb, 256-dim) is injected into every ResBlock via an additive time-conditioning module.

§ 04 — Blocks

The building blocks.

Every block in the UNet is one of five patterns. Click the matching node in the canvas above to see it live.

ResidualBlock

Two convolutional layers with time-embedding injection between them, wrapped in a residual connection. GroupNorm + SiLU for activations; a small dropout after the second SiLU. When input and output channel counts differ, the residual path uses a 1×1 projection; otherwise identity.

AttentionBlock

Standard spatial self-attention, computed by flattening H×W into a sequence dimension and running nn.MultiheadAttention with need_weights=False (which triggers PyTorch's fused SDPA path). The residual around the attention path is essential — without it, attention replaces its input rather than refining it.

DownBlock & UpBlock

A DownBlock is block_depth × ResidualBlock (harvesting skip tensors along the way) → optional AttentionBlock → stride-2 3×3 conv for downsampling. The UpBlock is the mirror: nearest upsample followed by a 3×3 conv (the conv is essential to avoid checkerboard artifacts), then ResBlocks that concatenate the skip tensor as extra input channels, then an optional AttentionBlock.

MidBlock

An alternating res→attn→res→attn→…→res sandwich at the bottleneck resolution. n_res_blocks = 3 ResBlocks with attention interleaved between them — the model's chance to do long-range reasoning on a small spatial grid.

Time-conditioning modules

Two variants supported via the time_embedding_norm config: additive (project temb to C_out channels and add) and film (project to 2·C_out and apply scale/shift, a la FiLM). Default is additive.

§ 05 — Math

Forward, reverse, and the samplers.

Forward process

Given a clean latent x₀, the forward process produces a noised sample at any timestep t: 

x_t = α(t) · x₀ + σ(t) · ε,     ε ∼ N(0, I)

The cosine schedule sets angles between acos(sched_max) and acos(sched_min), and defines α(t) = cos(angle(t)), σ(t) = sin(angle(t)).

Reverse (DDIM η=0)

x̂₀ = (x_t − σ_t · ε̂) / α_t
x_{t−1} = α_{t−1} · x̂₀ + √(1 − α²_{t−1}) · ε̂

Reverse (DPM-Solver++ 2M multistep)

x̂₀_effective = (3/2) · x̂₀_t − (1/2) · x̂₀_{t+Δ}       (Adams-Bashforth 2M)
x_{t−1} = (σ_{t−1}/σ_t) · x_t + α_{t−1} · (1 − e^{−h}) · x̂₀_effective
h = log(α_{t−1}/σ_{t−1}) − log(α_t/σ_t)

Higher orders (3M) use one more cached x̂₀ and different Adams-Bashforth coefficients — computed at runtime by solving a small Vandermonde system in _compute_ab.

§ 06 — Training

The loop, in ~15 lines.

# DiffusionModel.train(), simplified
for img, class_idx in loader:
    t   = torch.randint(0, T, (B,))
    eps = torch.randn_like(img)
    sr, nr = signal_rates[t], noise_rates[t]
    noisy  = sr·img + nr·eps

    # CFG training: mask a fraction of class labels to null
    if torch.rand(B) < uncond_prob:
        class_idx = 0

    with autocast(bf16 if supported else fp16):
        eps_pred = model(noisy, t, class_idx)
        loss     = MSE(eps_pred, eps)

    scaler.scale(loss).backward()
    scaler.unscale_(opt); clip_grad_norm_(1.0)
    scaler.step(opt); scaler.update()
    ema.update_parameters(model)

Notes worth pointing at: bf16 is chosen automatically on Ampere+ (with an fp16 fallback), the EMA has decay 0.9999, and gradients are clipped to global norm 1.0 before every step.

§ 07 — Sampling

Two samplers, one model.

Both DDIM and DPM-Solver++ multistep share the sampling scaffolding — timestep schedule, CFG wrap, x₀ return trick at the end. They differ only in the update rule inside the loop. 

# DiffusionModel.sample(), simplified
x = torch.randn(size)
schedule = linspace(T-1, 0, n_steps + 1).long()

for t, t_prev in zip(schedule[:-1], schedule[1:]):
    with autocast(...):
        eps = cfg_wrap(ema, x, t, class_labels, guidance_scale)
    x_0 = (x − nr[t]·eps) / sr[t]

    if dpmpp_order:
        # DPM++ multistep: extrapolate x_0 from cached prev estimates
        x_0_prev.insert(0, x_0)
        coeff = _compute_ab(dpmpp_order)
        x_0_eff = sum(c·x for c, x in zip(coeff, x_0_prev))
        h  = log(sr[t_prev]/nr[t_prev]) − log(sr[t]/nr[t])
        x  = (nr[t_prev]/nr[t])·x + sr[t_prev]·(1 − exp(−h))·x_0_eff
    else:
        # DDIM η-parameterized update
        sigma = eta · (nr[t_prev]/nr[t]) · √(1 − sr[t]²/sr[t_prev]²)
        x = sr[t_prev]·x_0 + √(1 − sr[t_prev]² − sigma²)·eps + sigma·randn()

return x_0   # cleaner than x at the last step (cosine schedule)
